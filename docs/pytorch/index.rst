*******
PyTorch
*******

`PyTorch <https://pytorch.org/>`__ is an open-source tensor computation and
deep learning framework that provides flexible, high-performance tools for
research and production. On AMD GPUs, PyTorch is optimized through ROCm math
and compute libraries, enabling scalable, efficient training and inference
across a wide range of workloads.

To get started with PyTorch on AMD GPUs, review the :doc:`release notes
<release/latest>`, :doc:`support overview <support>` information, and
:doc:`installation instructions <install>`.
