***
JAX
***

`JAX <https://docs.jax.dev/en/latest/index.html>`__ is a library for
array-oriented numerical computation, similar to NumPy, designed for
high-performance machine learning and scientific computing. JAX combines
composable function transformations with just-in-time (JIT) compilation and
automatic differentiation to enable expressive, efficient research workflows.
By building on the Accelerated Linear Algebra (XLA) compiler, JAX allows
numerical Python code to run efficiently on CPUs, GPUs, and other accelerators,
scaling from single-device experiments to large distributed systems.

To get started with JAX on AMD GPUs, review the :doc:`release notes <release/latest>`,
:doc:`support overview <support>` information, and :doc:`installation
instructions <install>`.
